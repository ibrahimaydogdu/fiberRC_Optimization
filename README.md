# Lifli Betonarme Çerçeve Optimizasyonu — Makale Projesi (SedaDoktora3)

Çelik lifli (SFRC) kirişli betonarme çerçevelerin ETABS OAPI ile entegre meta-sezgisel maliyet optimizasyonu makalesi. Kaynak: S. Turan doktora tezi; düzeltme yöneticisi: İ. Aydoğdu.

| Klasör | İçerik |
|---|---|
| `AGENTS.md` | Çok ajanlı yönetmelik (Claude + Gemini ortak) |
| `CLAUDE.md`, `GEMINI.md` | Araç giriş dosyaları (AGENTS.md'yi içe aktarır) |
| `MEMORY.md` | Kalıcı proje hafızası |
| `00_System/` | Master, kurallar, durum, görevler, HANDOFF, GEMINI_SYNC, program referansı |
| `01_Literature/` … `06_Review_Audit/` | Ajan promptları ve aşama çıktıları |
| `Sources/` | **Salt-okunur** kaynaklar (tez, makale metinleri, Excel, program, ETABS modelleri) |
| `Papers/`, `Evidence/` | Orijinal kaynak PDF/XLSX (git dışı) |

Durum: Aşama 0 (kaynak envanteri + yapı kurulumu). Sıradaki adım `MEMORY.md` §5.
